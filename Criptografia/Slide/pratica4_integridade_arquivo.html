❓ Por que comparar somente o nome do arquivo ou o tamanho não é suficiente para verificar integridade?
Porque é trivial para qualquer atacante ou falha de sistema manter exatamente o mesmo nome e o mesmo número exato de bytes adulterando o conteúdo interno:
1. Substituição de dados sem alterar tamanho: Trocar uma conta bancária de 8 dígitos por outra com os mesmos 8 dígitos mantém o tamanho do arquivo em bytes perfeitamente idêntico.
2. Ataques em binários/código: Modificar instruções de uma aplicação ou injetar malware preenchendo o restante com bytes nulos (padding) preserva o tamanho exato.
Portanto, somente uma função criptográfica com alta resistência a colisões e efeito avalanche (como SHA-256) garante que cada bit interno permaneceu inalterado.
